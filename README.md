<h1>Java project fot import text files into <i>transactions objects</i></h1>
<h3>Demo project for import <i>HTML, CSV, JSON</i> text files into the transactions system.</h3>
<decription><b>About project:</b> Importer classes import text files into banking transactions with the following parameters: amount, date, transaction description. After import, all calculations are performed in the BankStatementProcessor service. Classes have also been implemented that allow for exporting a summary of all transactions.</decription>
<h3>Technology stack: Java 21, JUnit 4</h3>
